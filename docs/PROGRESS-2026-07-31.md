# Goal progress — 2026-07-31

This checkpoint records the first verified tranche of the ongoing app-wide
improvement goal. It supersedes the simulator/toolchain blockers recorded in
`AUDIT-2026-07-17.md`; that audit remains as historical evidence.

## Delivered

- Restored a clean Xcode build by fixing missing engine imports, extension
  visibility, and an exhaustive UI-test action mapping.
- Added a genuinely separate regular-width iPad lobby composition. iPhone
  keeps the compact single-column flow; iPad uses a two-region setup and the
  game continues to use its tablet scoresheet sidebar.
- Rebalanced the live iPad table around gameplay. The persistent scoresheet now
  uses a bounded 280–340 point column instead of a fixed 360 point claim, while
  opponent hands and the prikup use tablet-scale cards. Compact iPhone layouts
  retain their existing sizing and composition.
- Made the screenshot helper bounded and targetable with exact simulator and
  individual-test selection, and repaired the portable engine test helper for
  sandboxed Xcode toolchains.
- Corrected the canonical Sochi profile to use talon-led raspasy and amnesty.
- Corrected Leningrad recording and balance scales: made contracts retain the
  standard pool ladder, mountain/direct whists are doubled, a pool point is 20
  whists, and a mountain point remains 10 whists.
- Split pulka closure into explicit convention policies. Sochi still closes
  every individual pool and redirects surplus through American aid; Leningrad
  now leaves individual pools open, writes no aid, permits the winning entry to
  overshoot, and closes only when the shared table total is reached.
- Rejected bounded individual targets that cannot divide across all seats, and
  made open/terminal snapshot state agree with the selected closure policy.
  Corrupt resumed snapshots now throw during construction instead of reaching
  an engine precondition trap.
- Corrected responsible-whist settlement to judge the defending partnership
  collectively. An uneven individual share is not penalized when the joint
  quota is met; a failed partnership uses the fixed half-share remise.
- Routed rule-specific conversion values through pulka closure, American aid,
  score displays, match summaries, and terminal-state invariant validation.
- Removed a task-local clock race from the online-name persistence tests.
- Rebuilt local bot seats around stable difficulty and temperament profiles.
  Difficulty now controls hidden-card search depth; temperament changes
  borderline bidding, whist responsibility, open/closed defensive play, and
  card-play risk. Careful bots discount volatile rollouts, adaptive bots
  maximize expectation, and bold bots accept controlled upside.
- Fixed the rollout policy that previously made defenders try to lose tricks
  during ordinary contracts. Defenders now take the cheapest winner and avoid
  overtaking a partner who already owns the trick.
- Replaced the card planner's hard-coded trick bonus with the real normalized
  pool/mountain/whist balance under the active convention, and removed a
  no-op rollout option that repeated the identical deterministic simulation.
- Added player-facing bot profile controls to both compact iPhone and
  two-region iPad lobbies. Stock opponents now have distinct identities:
  Morpheus is careful/expert, Trinity is bold/seasoned, and Agent Smith is
  adaptive/expert.
- Replaced the trust-based multiplayer API with a clean-break v2 account and
  room protocol. Guests receive server-issued identities; Sign in with Apple
  tokens are verified against Apple keys, audience, expiry, and nonce before
  an account session is issued.
- Made multiplayer authorization account-owned and seat-scoped. Bearer
  sessions live in the device-only Keychain, seat tokens remain room-scoped,
  and room creation, joining, recovery, snapshots, abandonment, and host-only
  operations reject missing or mismatched authority.
- Removed client-declared human identity, host secrets, legacy endpoint
  compatibility, and optional seat-token enforcement. Fresh Durable Object
  namespaces and schema version 2 intentionally require every user to
  register again.
- Removed the dormant CloudKit multiplayer/archive implementation and iCloud
  entitlement. The authenticated Cloudflare room service is now the sole
  online account, game-library, durability, and recovery source of truth.
- Added an authenticated game library and registration-first online lobby,
  including a first-class guest path, Apple nonce binding, accurate settings
  and privacy copy, and localized English, Russian, and Ukrainian UI.
- Added worker and Swift contract tests for registration, bearer-only library
  access, identity-free room creation, wrong-account token theft, Apple claim
  validation, strict room ownership, and the full create-to-abandon lifecycle.
- Made realtime host authority recoverable instead of device-local. Every room
  now carries a monotonic host epoch; when the host disconnects, the worker
  elects the first connected human in stable seat order and broadcasts the new
  authority to every participant.
- Made a seat credential single-device in practice. Rejoining the same account
  rotates the credential, closes an older live socket with an explicit
  `seat_replaced` event, and turns the displaced iOS session read-only instead
  of allowing two devices to control one hand.
- Made recovery fail closed. A playing room without a valid durable snapshot no
  longer fabricates a fresh lobby, terminal rooms cannot be resurrected, and a
  stale host report cannot regress the saved summary.
- Added a durable-before-visible action barrier. A host action is committed to
  the room worker before its new projection is shown to clients; failed commits
  retain the previous visible state and retry with a bounded backoff. Promotion
  rehydrates the exact committed snapshot, while demotion discards unpublished
  local state.
- Added player-facing reconnecting, host-recovery, and newer-device banners to
  both waiting-room and live-table online screens.
- Extracted online seat ownership from the room coordinator into a pure roster
  model. It now enforces human-over-placeholder precedence, duplicate-seat
  tolerance, bot identity synchronization, idempotent no-show conversion, and
  hello admission without relying on transport timing.
- Made the convention selector available to bot tables as well as online
  tables, so choosing Wien now seeds both the Leningrad deal rules and its
  shared-total match policy locally. Its localized summary calls out the shared
  pool instead of describing only whist behavior.
- Gave the iPhone lobby an opaque dark navigation/status surface with matching
  light system icons, preventing scrolled fields from colliding with the status
  bar or settings control.
- Added persistent multi-deal raspasy series state. Sochi now prices consecutive
  deals at 1–2–3 and Leningrad at 2–4–6, both capped at stage three; strict
  exit auctions require games of 6, then 7, then 8 tricks and reset after a
  non-raspasy result. The stage survives snapshots and is invariant-checked.
- Rebuilt the rules sheet as an engine-backed scoring reference. It calculates
  contract, whist, misère, pool-closing, and raspasy examples with production
  code, uses a compact convention picker on iPhone, and a persistent navigation
  sidebar on iPad. An in-game entry shows the exact active table configuration.
- Added public-safe bot decision explanations. Strategic auction, discard,
  contract, whist, defender-mode, and settlement choices briefly explain
  themselves on the felt and remain in a bounded activity log without exposing
  cards, evaluator values, or hidden-hand samples.
- Made bot explanations phase-aware on the felt. Whist and defender-mode notes
  now use the otherwise empty center lane, avoiding opponent-card collisions;
  prikup and trick-play notes keep their higher lane so they do not cover cards.
